# 심연의 기사

화면을 그은 방향으로 돌진해 연달아 베며 심연을 내려가는 다크 판타지 액션 로그라이크입니다. 가로로 든 폰으로 하고, 기사가 쓰러지면 아들이, 손자가 대를 이어 더 깊은 층으로 내려갑니다. 지금 개발 중입니다.

**플레이:** https://woomars.github.io/abyss/

가문 기록, 보관함, 설정은 쓰고 있는 브라우저에만 남습니다.

개인 재미를 위한 비상업 프로젝트입니다. 효과음과 배경음악은 [Pixabay](https://pixabay.com/)에서 받아 다듬었고(Pixabay 콘텐츠 라이선스), 곡과 효과음마다 만든 사람과 원본 주소는 [assets/audio/CREDITS.md](assets/audio/CREDITS.md)에 있습니다. 시작 스토리의 배경 그림도 Pixabay에서 받았고(출처: [assets/images/CREDITS.md](assets/images/CREDITS.md)), 나머지 소리는 Web Audio로 직접 합성했고 나머지 그림은 코드로 그렸습니다. 코드와 직접 만든 그림은 MIT 라이선스([LICENSE](LICENSE))이고, 그 밖의 자료는 위에 적은 각 라이선스와 권리를 따릅니다.
